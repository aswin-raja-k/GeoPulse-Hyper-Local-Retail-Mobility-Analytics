# GeoPulse-Hyper-Local-Retail-Mobility-Analytics
Hyper-local retail mobility analytics using data analysis and interactive visualizations.



###Dataset Description

The GeoPulse project uses a simulated GPS mobility dataset based on Madhapur, Hyderabad.

###Dataset Details

- Total records: 5,000
- Number of devices: 50
- Records per device: 100
- Columns: DeviceID, Latitude, Longitude, Timestamp

###Dataset Validation

- No missing values
- No duplicate records
- Coordinates within the Madhapur study area
- Chronological timestamps for each device
- Simulated GPS movement patterns

###Important Note

This dataset contains simulated GPS data generated for research and development purposes. It does not represent actual GPS data collected from real devices or individuals.
