# GeoPulse – Hyper-Local Retail Mobility Analytics



## 1. Project Overview

GeoPulse analyses simulated, anonymized GPS data to understand customer movement, retail footfall and store catchment areas.



## 2. Project Objectives

- Identify hourly footfall patterns.

- Analyse store catchment areas.

- Understand customer movement between stores.

- Identify potential store cannibalisation.

- Present useful business insights through dashboards and maps.

## 5. Dataset Structure



| Column | Description |

|---|---|

| DeviceID | Anonymized device identifier |

| Latitude | GPS latitude |

| Longitude | GPS longitude |

| Timestamp | Date and time of GPS record |



Only simulated or anonymized data will be used.



## 6. Project Workflow



1. Generate simulated GPS data using Python.

2. Clean and validate the dataset using Excel.

3. Store and analyse records using MySQL.

4. Perform catchment and spatial analysis using PostGIS.

5. Visualise geographical patterns using Kepler.gl.

6. Build business dashboards using Power BI.

7. Automate the workflow using Apache Airflow.
